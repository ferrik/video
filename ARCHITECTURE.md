# Creator OS — Architecture & Vision

## Суть проекту
Ми будуємо **не просто сайт і не просто генератор відео**, а **автоматизовану контент-фабрику**, яка майже без ручної роботи проходить весь шлях від ідеї до готового матеріалу для публікації.

Простими словами, система працює так:
```text
натиснув одну кнопку
→ система сама знайшла тему
→ написала сценарій (script)
→ зробила озвучку (voice)
→ підібрала кліпи (clips)
→ зібрала відео (render)
→ підготувала title, caption, hashtags, affiliate link
→ віддала готовий пакет (publish package)
```

## Що це за проект?
Це **Creator OS** — операційна система для контенту. Її задача не просто “згенерувати ще одне відео”, а:
* знаходити теми, які мають шанс спрацювати
* швидко перетворювати їх у відео
* збирати результати
* знаходити переможців
* масштабувати те, що реально зайшло

Тобто головна бізнес-логіка:
```text
знайти тему → зробити контент → подивитися результат → зрозуміти, чому спрацювало → повторити сильний патерн
```

## Factory-First підхід
Ми переходимо від "набору інструментів" до **одного автоматичного процесу**.
На головному екрані має бути тільки найважливіше:
* тема
* продукт
* ринок
* платформа
* тривалість
* кнопка **“Запустити фабрику”**

Після натискання фабрика повністю бере оркестрацію на себе (під капотом).

### Що система робить під капотом:
Тут знаходиться автоматизований ланцюг:
```text
topic → script → voice → clips → render → publish package → save result
```

Наразі система доходить до етапу **"Готово до публікації"** і видає:
* готове змонтоване відео
* заголовок та опис
* хештеги та affiliate link
* примітки для публікації

Сама публікація поки що відбувається вручну (завантажив пакет -> виставив), оскільки для стабільності нам спочатку потрібен **один стабільний повний цикл генерування**.

## Стійкість та Архітектурний Патерн (Fail → Switch → Continue)
Головне місце, де ламається AI-бізнес — це не власний код, а **зовнішні сервіси та їх ліміти**.

У Creator OS ми впровадили філософію відмовостійкості:
```text
try ElevenLabs
if fail → Switch to OpenAI TTS
if fail → Continue (збережи всі готові тексти і кліпи для ручної склейки)
```
Це гарантує, що система не скасовує всю роботу через один ліміт, а завжди доводить "job" до контрольної точки.

## Мобільний режим
Окрім десктопного інтерфейсу, система має **мобільний режим** — спрощену версію, де з телефона можна:
* оптимізувати налаштування
* натиснути запуск фабрики
* швидко подивитися статус завдання та результат

Телефонний режим створений для швидкої генерації на ходу, без потреби занурюватися в глибоку аналітику.

## Головний сенс
Кінцева ціль не “мати красивий AI-інтерфейс”, а зменшити ручний хаос:
```text
отримувати більше готових відео
→ швидше тестувати теми
→ знаходити переможців
→ заробляти (affiliate commission) на тому, що вже спрацювало
```
Creator OS — це **однокнопкова AI-фабрика контенту**, яка перетворює ідеї у машинозгенерований потік відео.
